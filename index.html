Judge guide: full journey in ~2 minutes
  1. Meera (owner) → Listings: add a resource with conditions (or use the seeded ones).
  2. Tom (community maker) → Discover → 3D Printer Bay: see eligibility gaps, submit credentials. Meera → Verifications: approve.
  3. Asha or Tom → request a slot. Request the same slot as Ravi’s (tomorrow 10:00) to see the automatic waitlist.
  4. Meera → Requests: approve / waitlist / reject with a reason; competing requests are ranked by fair-use priority.
  5. Requester → My bookings: ⏩ jump to start, check in with condition, return as “Damaged”, or ⏩ pass the end time for an overdue flag.
  6. Owner → confirm return, resolve incidents. Every step appears in each booking’s History and the Audit tab.
